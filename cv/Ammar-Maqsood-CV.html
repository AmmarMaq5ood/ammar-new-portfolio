How I work with AI

Spec first. Goals, data shapes and API contracts go into the repo before the first prompt.

Context, not re-explaining. Every repo carries a CLAUDE.md / AGENTS.md and a project-context file, so a fresh session starts warm and tokens go to the work.

Scoped tasks, delegated searches. Big jobs are split into small ones, long explorations go to subagents, and repeat work becomes a skill or slash command.

Right model for the job. Cheaper models for routine edits, the strongest for architecture; AI spend metered in the products I build.

Review everything. Agent output is a draft until it typechecks, passes tests and runs locally.
